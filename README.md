🍫 Chocolate Sales Analysis

📊 Project Overview

This project analyzes chocolate sales data to uncover sales trends, top-performing products, country-wise performance, and shipment patterns. The analysis transforms raw sales data into meaningful business insights using data cleaning, KPI analysis, and visualization.

🎯 Objectives

  Analyze overall sales and revenue performance
  Identify top-selling chocolate products
  Compare sales across different countries
  Analyze monthly and quarterly trends
  Evaluate boxes shipped and revenue per box
  Generate actionable business insights

🛠️ Tools & Technologies

Excel – Data cleaning and analysis
Python – Data processing and EDA
Pandas & NumPy – Data manipulation
SQL – Data querying
Power BI – Dashboard and visualization

📈 Key Insights

The project highlights important sales patterns, high-performing products and regions, and trends that can help businesses understand their sales performance and make data-driven decisions.
